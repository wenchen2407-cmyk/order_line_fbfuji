一、Google Sheets 後端測試資料清除操作

在後端 Google Apps Script（src/gas/Code.gs）中，已準備好「安全清除函式」：
只會清空第 2 列以後的所有測試資料，【完整保留第 1 列表頭結構、欄位背景色與格式設定】，絕不會誤刪工作表或系統設定。

【執行方式（最直覺推薦）：】
1. 開啟您的 Google 試算表。
2. 點選上方選單的 「擴充功能」 ➔ 「Apps Script」。
3. 在編輯器頂部的函式下拉選單中，選擇「clearTestOrdersData」（或 clearOrdersAndCustomers）。
4. 點擊「執行 ▶️」。
5. 執行完成後，「訂單明細」與「顧客歸戶」的測試資料即全數清空。

【網址 API 一鍵執行（需部署新版 GAS Web 應用程式）：】
若您後續重新部署了 GAS Web 應用程式，也可以直接在瀏覽器開啟以下 API 網址一鍵清理：
https://script.google.com/macros/s/AKfycbzz5Upj-2ho-n6kdWqffD3a0B6xNki6FYjwrQP7RVDP9d41PALA-6JVZeeC1CnJn7ZG/exec?action=clearTestData


二、前端本地快取清除與空狀態驗證

先前在本地測試時會自動載入示範假資料，導致清空後在本地端仍可能看到示範訂單。現已全面優化機制：

1. 一鍵重置本地快取（空狀態驗證）：
   請直接點擊或開啟本機連結：
   http://localhost:8888/my-orders.html?clear=1
   瀏覽器會自動清空 sessionStorage 與 localStorage 快取，並呈現真實的「🛍️ 目前尚無連線訂購中的商品！」空狀態畫面。

2. 保留示範模式：
   只有在網址明確帶入 ?demo=1 時，才會載入包含三種狀態的示範卡片，方便隨時向他人展示版面：
   http://localhost:8888/my-orders.html?demo=1
