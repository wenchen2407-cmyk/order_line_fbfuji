一、網頁基礎資訊 (Meta & Page Title)
--------------------------------------------------------------------
1. 瀏覽器分頁標題 (<title>)：
   連線代購即時訂購單

2. 語言與編碼設定：
   - 語系：zh-TW（繁體中文）
   - 編碼：UTF-8
   - 響應式 Viewport：width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no


二、頂部快速導航列 (Top Navigation Bar)
--------------------------------------------------------------------
位於頁面最頂部，提供買家快速切換商品大廳與個人訂單清單：

1. 返回商品大廳按鈕：
   - 按鈕顯示：🛍️ 更多商品
   - 點擊行為：跳轉至連線商品大廳首頁 (catalog.html?uid={LINE_User_ID})

2. 查看訂購清單按鈕：
   - 按鈕顯示：📦 訂購清單
   - 點擊行為：跳轉至個人連線訂單彙整頁面 (my-orders.html?uid={LINE_User_ID})


三、買家身分識別列 (LINE User Badge)
--------------------------------------------------------------------
自動整合 LINE LIFF 與本地快取，展現 0 毫秒極速辨識效果：

1. 買家大頭貼 (Avatar)：
   - 圓形頭像，若尚在驗證或訪客模式時顯示預設頭貼

2. 身分識別狀態文字：
   - 載入驗證中：正在驗證 LINE 帳號...
   - 成功連線 (正式環境)：{LINE顯示暱稱} (已連線)
   - 外部瀏覽器 / 訪客模式：{LINE顯示暱稱} (訪客預覽)
   - 本地測試環境：未啟用 LIFF (本機測試模式) 或 {LINE顯示暱稱} (本機模式)


四、商品主展示卡片 (Product Detail Card)
--------------------------------------------------------------------
1. 商品圖片與多圖縮圖切換列 (Product Images & Gallery)：
   - 商品主圖展示 (支援 Google Drive 自動轉直連解析、無損高畫質全圖呈現)
   - 多圖頁數計數標籤 (右下角毛玻璃徽章，多於 1 張時顯示)：
     {當前張數} / {總張數}（例：1 / 4）
   - 縮圖切換列 (底部橫向滑動按鈕)：
     點擊縮圖即時平滑切換主圖，並高亮綠框聚焦

2. 現貨庫存狀態徽章 (Stock Badge)：
   - 徽章位置：主圖右上角深色半透明標籤
   - 顯示文字：剩餘現貨：{現貨數量}（例：剩餘現貨：15）
   - 隱藏邏輯：若庫存 >= 9999 (常態不限名額) 或 <= 0 時自動隱藏

3. 收單截止動態倒數晶片 (Deadline Banner)：
   （同步連動試算表【系統設定】的 ORDER_DEADLINE）
   - 未設定截止時間 (欄位留空)：
     視為目前無時間限制，本倒數晶片自動完全隱藏不顯示。
   - 正在收單中 (未逾截止時間)：
     ⏳ 本次連線收單倒數：{天}天 {時}小時 {分}分 {秒}秒
     （例：⏳ 本次連線收單倒數：1天 08小時 12分 45秒）
   - 已截止收單 (關單狀態)：
     ⛔ 本次連線已收單
     （自動連動底部送單按鈕鎖定為已截止「🚫 已截止登記」）

4. 分類期別標籤與商品標題 (Category & Title)：
   - 連線期別/分類標籤：{商品分類}（預設：2026.10月連線）
   - 商品標題占位：載入商品資料中...
   - 正式商品標題：{商品名稱}（例：日本代購限定 輕量防潑水後背包）

5. 商品價格區塊 (Price Box)：
   - 連線特惠價 (大字粗體橘紅)：NT$ {售價}（例：NT$ 1,450，初始占位：NT$ ---）
   - 專櫃參考原價 (灰色劃線刪除線)：NT$ {原價}（例：NT$ 1,880，初始占位：NT$ ---）
     * 規則：僅當原價存在且高於連線特惠價時顯示；若未填或原價小於等於售價則完全隱藏

6. 商品詳細說明 (Product Description)：
   - 初始占位：商品描述準備中...
   - 正式內容：{商品文案、尺寸規格、材質說明與代購注意事項}
   - 預設備案：日本專櫃代購正品，數量有限敬請把握！


五、規格款式與數量選購區 (Form Section: Specs & Quantity)
--------------------------------------------------------------------
1. 款式規格選擇 (Spec Pills)：
   - 區塊標題：選擇款式與數量
   - 欄位標籤：規格款式
   - 規格膠囊按鈕：{規格名稱}（例：[經典黑]、[燕麥米白]、[海軍深藍]）
     * 選取狀態：綠底綠框深色字
     * 無特別規格時：顯示「單一規格」

2. 購買數量增減控制 (Quantity Control)：
   - 欄位標籤：購買數量
   - 減號按鈕：[-]（最低為 1）
   - 數量顯示輸入框：{數量}（預設：1，鎖定鍵盤唯讀，防呆點擊）
   - 加號按鈕：[+]（上限連動商品剩餘庫存數）
   - 數量超額防呆警示 (Alert)：
     已達到目前現貨/連線登記上限！

3. 訂單備註欄位 (Order Notes)：
   - 欄位標籤：訂單備註 (選填)
   - 輸入框 Placeholder：如有尺寸、顏色替補順位等特殊需求可備註


六、連線代購必讀說明卡 (Policy & Notice Section)
--------------------------------------------------------------------
灰色底框連線規範卡片，保障買賣雙方權益：

【卡片標題】
✈️ 連線代購必讀

【規範條款】
• 🚫 下單即確定購買，不可取消或刪改，下單前請確認規格、數量。
• ⚡ 依下單順序配貨，若遇缺貨將主動變更狀態。
• ⏰ 收單截止時間以群組最後公告之截單時間為主。確認結單時間也會同步於商品清單頁上。
• 📦 待清查完畢後，將於群組或私訊確認訂單資料並發送專屬賣場連結供下單出貨。
• 🚚 出貨運費：超商純取 0 元免運；賣貨便/好賣+ 滿 3,000 元免運；亦支援郵寄與宅配（依選擇之寄送方式計費）。


七、底部固定搶購工具列 (Bottom Floating Bar)
--------------------------------------------------------------------
固定懸浮於手機螢幕底部，毛玻璃透明質感：

1. 左側金額結算區 (Total Summary)：
   - 標籤文字：商品金額小計
   - 小計金額：NT$ {小計總額}（單價 × 數量，例：NT$ 1,450）

2. 右側火速送單按鈕 (Submit Button)：
   - 正常可登記狀態：🚀 火速登記 (LINE 綠色漸層亮面按鈕)
   - 送單傳輸中狀態：登記中.... (按鈕禁用防重複點擊)
   - 收單逾期關單狀態：🚫 已截止登記 (灰色鎖定，不可點擊)


八、首次使用建立聯絡資料彈窗 (First-time Customer Modal)
--------------------------------------------------------------------
新客首次開啟或送單時觸發，僅需填寫一次即可終身自動綁定歸戶：

1. 視窗標題區：
   - 主標題：首次使用，請建立聯絡資料
   - 副標題：僅需填寫一次

2. 填寫欄位與預設提示：
   - 欄位一：LINE 顯示暱稱
     * 輸入框 Placeholder：自動帶入中...（由 LIFF 自動帶入，唯讀淺灰背景）
   - 欄位二：真實姓名 *
     * 輸入框 Placeholder：請填寫證件相符真實姓名
   - 欄位三：手機號碼 *
     * 輸入框 Placeholder：09xxxxxxxx

3. 操作按鈕：
   - 確認按鈕：[確認送出]（寫入資料中切換為：建立歸戶中...）
   - 放棄按鈕：[取消]

4. 前端資料防呆驗證警示 (Alert)：
   - 未填真實姓名：請填寫「真實姓名」，以利回國後核對訂單與寄件！
   - 手機格式不符：請填寫正確的手機號碼 (例如：0912345678)！
   - 首次填寫完成提示 (若非直接下單)：
     ✅ 聯絡資料已成功建立並歸戶！現在您可以挑選喜愛的商品規格並進行登記囉！

2. 訂購資訊明細卡：

3. 後續導航按鈕組：

   - 看清單按鈕：[📦 查看訂購清單]（導向 my-orders.html?uid=...）


十、全系統動態參數、例外警示與資料表連動對照
--------------------------------------------------------------------
1. 網址參數 (Query Parameters)：
   - ?p= 或 ?pid= 或 ?productId= 或 ?id=：指定載入之商品 ID（預設 fallback：P001）
   - ?uid=：LINE User ID（支援網頁跳轉連動帶入身分）
   - ?reset=1 或 ?new=1 或 ?clear=1：開發測試專用，強制清除本地身分快取重新模擬新客

2. 系統錯誤與連線異常提示 (Alerts)：
   - 商品查詢失敗：商品不存在
   - 訂單建立被拒：登記失敗：{GAS回傳之錯誤訊息}
   - 網路連線中斷：網路連線逾時，請檢查網路或稍候再試！

3. 極速架構連動 (0 毫秒秒開)：
   - 自動讀取商品大廳 sessionStorage 預載之商品資訊，買家點進商品內頁完全零等待
   - 智慧驗證試算表【顧客歸戶】工作表真實資料，老客享有「點擊即秒單」流暢體驗
